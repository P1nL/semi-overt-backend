# distributed-refactor 归档说明

这组文档是本仓库从单体思路走向多模块微服务过程中的历史改造资料，用来保留当时的拆分设计、迁移计划和阶段性判断，不作为当前仓库的主阅读入口。

## 这组文档适合什么时候看

- 你想追溯为什么服务会按现在的方式拆分
- 你想理解事件驱动、搜索投影、通知派生这些设计最初是怎样被规划出来的
- 你在评估某项历史决策是否仍然成立

## 这组文档不适合替代什么

- 不适合替代当前项目总览
- 不适合替代当前逐文件详细讲解
- 不适合作为当前上线和运行文档

当前仓库的正式阅读入口应优先看：

- [项目总览](../../01-overview/01-project-overview.md)
- [后端主题导读](../../02-backend-guide/01-api-and-auth.md)
- [运行与上线文档](../../03-runtime-and-delivery/01-local-development.md)
- [逐文件详细讲解](../backend-understanding/README.md)

## 为什么它仍然保留

- 历史设计文档能解释很多“现在为什么这样做”的背景
- 某些旧线程提示、拆分计划、迁移推演仍然有参考价值
- 但其中大量“准备要做”“后续接入”的语气已经不是当前事实

因此，这一组文档只保留为历史改造背景，不再承担当前结构说明职责。
