# 全栈新人指南

适合谁看：第一次接触这个项目的初级开发者，想从零读懂前端 + 后端的完整体系。
读完能解决什么问题：知道项目用了什么技术、为什么这样分层、一次请求从用户点击到数据库再到页面更新的完整路径。

## 建议阅读顺序

1. [项目全景：技术栈、模块关系与阅读路径](./01-project-panorama.md)
2. [架构设计分析](./02-architecture-analysis.md)
3. [登录功能全链路追踪](./03-login-flow-trace.md)

## 这一组文档回答什么

- 前后端各用了哪些技术，每个技术在项目里负责什么
- 前端的 FSD 分层和后端的微服务分层各自的职责边界
- 公共基础设施代码（统一响应、拦截器、事件系统等）在哪里、做什么
- 前后端如何协作，接口规范和数据格式是什么
- 一次完整请求从前端表单提交到数据库查询再到页面跳转经历了哪些步骤

## 前置知识

- 基本了解 HTML / CSS / JavaScript / TypeScript
- 基本了解 Java / Spring Boot
- 知道什么是 HTTP 请求和 JSON
- 不需要提前了解 Vue、MyBatis Plus 或微服务架构，文档中会在用到时解释
