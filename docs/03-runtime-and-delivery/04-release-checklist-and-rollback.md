# 04 上线检查与回滚

## 发布前检查表

### 代码与制品

- 已锁定本次发布版本
- 已完成 `mvn clean package`
- 目标服务 Jar 已生成且版本正确
- 未误用旧包或 `*.original` 包

### 配置

- 环境变量已核对
- Nacos `group`、`namespace` 正确
- 共享 dataId 已存在
- 服务级 dataId 已存在
- JWT 相关配置已确认一致

### 中间件

- MySQL 可访问
- Redis 可访问
- RabbitMQ 可访问
- Elasticsearch 可访问
- Nacos 可访问

### 存储与网络

- 服务端口未冲突
- 防火墙/安全组策略已确认
- 上传目录存在且可写，或对象存储准备完成
- Nginx 配置文件已准备好

## 发布中观察点

- 服务是否按既定顺序启动
- 每个服务的 `/actuator/health` 是否为 `UP`
- 每个服务的 `/actuator/info` 是否可访问
- Nacos 中实例是否注册成功
- 网关公开路由是否正常
- 无效 token 是否返回 `401`

## 发布后验收表

- 匿名访问首页成功
- 登录成功
- 受保护接口无 token 返回 `401`
- 创建文章成功
- 提交审核成功
- 审核通过成功
- 通知记录已落库
- 搜索结果可见
- 上传图片后可访问静态 URL

## 回滚触发条件

- 服务启动失败且短时间无法恢复
- 网关入口语义异常
- 关键主链路无法完成
- 通知或搜索异常已经影响发布目标
- 配置错误导致大面积不可用

## 回滚动作

### Jar 回滚

- 停止异常服务
- 替换为上一个稳定 Jar
- 按既定顺序重新启动

### 配置回滚

- 恢复 Nacos 配置
- 恢复环境变量
- 必要时重启受影响服务

### Nginx 回滚

- 恢复上一版 `now-demo.conf`
- `nginx -t`
- reload Nginx

### 搜索恢复

- 搜索异常优先通过 `search-service` 索引回填恢复
- 不直接把搜索异常视为文章主状态回滚依据

## 回滚后二次验证项

- 服务健康检查恢复正常
- Nacos 实例恢复正常
- 网关公开和受保护路由恢复正常
- 主链路重新通过：`登录 -> 提交审核 -> 审核通过 -> 通知 -> 搜索`
- 上传与静态资源访问恢复正常
